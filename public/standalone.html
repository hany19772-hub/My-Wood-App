دليل نشر الصفحة على GitHub Pages وربط Supabase

هذا الملف عبارة عن صفحة HTML متكاملة ومستقلة 100% (Single Page). بمجرد رفعها على مستودعك في جيت هاب، ستعمل مباشرة دون أي إعداد خادم.

1. نشر الصفحة على GitHub Pages

  1. أنشئ مستودعاً جديداً على GitHub باسم woodcraft-store.
  2. احفظ هذا الكود باسم index.html وارفعه للمستودع.
  3. اذهب إلى Settings ➔ Pages واختر فرع main واضغط Save.
  4. سيصبح متجرك متاحاً مجاناً للجميع برابط مباشر فوراً!

2. ربط تحديث الأسعار مع Supabase

  1. أنشئ مشروعاً مجانياً على Supabase وأنشئ جدولاً باسم products.
  2. أضف أعمدة: id, price, name_ar.
  3. ضع مفتاح الـ URL ومفتاح Anon Key في كائن SUPABASE_CONFIG أسفل الصفحة.
  4. أي تعديل في أسعار جدول Supabase ينعكس فوراً للزوار بدون إعادة رفع الكود!
